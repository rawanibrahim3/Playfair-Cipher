Playfair Cipher in Python

This is a simple Python project that encrypts and decrypts text using the Playfair Cipher.

Features

- Encrypt text using a secret key.
- Decrypt encrypted text.
- Use a 5×5 letter matrix.
- Replace J with I.

How to Run

1. Install Python.
2. Download the "playfair-task.py" file.
3. Run this command:

python playfair-task.py

4. Enter the key, text, and choose encryption or decryption.

Technology Used

- Python

Note

This project is for learning purposes. The Playfair Cipher is an old encryption method and is not secure enough for protecting sensitive information today.
